SmartPepper

A Blockchain-Enabled Real-Time Auction System for Verified Black Pepper Exports

Overview

SmartPepper addresses critical challenges faced by smallholder black pepper farmers in Sri Lanka and other producing nations. By integrating blockchain-backed traceability, transparent auctions, and automated compliance validation, we empower farmers to sell directly to exporters while ensuring regulatory adherence and building trust in the supply chain.

Core Features

🔗 Blockchain Traceability

Immutable digital passport for each pepper lot from farm to export, preventing fraud and building buyer confidence.

⚡ Real-Time Auctions

WebSocket-powered live bidding with sub-300ms latency enabling transparent price discovery and fair competition.

✅ Compliance Automation

Rule engine validates export regulations, certifications, and packaging standards before listing and shipment.

🎫 Smart Contracts

Automated escrow and settlement with secure payment release post-delivery and ownership transfer.

📱 Mobile-First Design

Flutter-based farmer app enabling lot registration, certification upload, and real-time bid tracking.

🌐 Web Dashboard

React/Next.js exporter portal for browsing lots, live bidding, compliance verification, and analytics.

Technology Stack

Blockchain: Solidity Smart Contracts, Hardhat, Ethereum (Sepolia testnet)

Backend: Node.js, Express, Firebase, Redis, IPFS

Real-Time: WebSocket for live auction updates

Frontend: Flutter (Mobile), React/Next.js (Web)
